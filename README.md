# Hospital Management System

A modern and scalable full-stack Hospital Management System built to simplify and digitize hospital operations.  
This project focuses on secure patient management, appointment scheduling, doctor workflows,and efficient medical record handling through a clean user interface and robust backend architecture.

---

## Live Demo
🔗 Live Project: https://hospital-management-system-0frk.onrender.com/

---

## Project Overview

The Hospital Management System is designed to improve the efficiency of healthcare management by providing a centralized platform for administrators, doctors, and patients.
The system enables secure authentication, appointment booking, patient record management, doctor scheduling, and role-based access control while maintaining scalability and clean architecture practices.

---

This project demonstrates practical implementation of:
- Full Stack Development
- REST API Integration
- Authentication & Authorization
- Database Management
- Responsive UI Design
- Backend Architecture using Spring Boot
